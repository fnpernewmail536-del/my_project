時間表示
サーバーのAPIには正確な残り時間がないため「予測」と表示します。
初回の目安は代行90秒、作成20+45×個数秒、複製45+60×個数秒です。
成功した処理の所要時間をこのブラウザに最大8件ずつ保存し、以後は中央値から予測します。
待機中・復元中・通信確認中は残り時間を「--」で表示します。
予測を超えた場合は「処理継続中」と表示し、完了通知を待ちます。
時間が0になっただけで完了扱いにすることはありません。
失敗や状態確認停止は完了演出を出しません。
結果コード・権限チェック・API認証・バックエンド処理は既存の実装を使います。

適用
ZIPのmy_projectフォルダの中身を、今のmy_projectに上書きしてください。
今のフォルダを削除して置き換える方法は使わないでください。
既存の.env、.git、.gitignore、Procfile、追加したBGMはそのまま残してください。
今回のZIPには.envとPythonのキャッシュを含めていません。
PowerShellで git add . / git commit -m "Add theme animations" / git push を実行。
Renderへの反映後、テーマ設定でエヴァまたはクラシックを選びます。
キャッシュ更新用のバージョンはv35です。
Windows/Androidの「アニメーションを減らす」設定時は動きを抑えます。
演出用の外部動画・音声の埋め込みや自動再生は追加していません。
