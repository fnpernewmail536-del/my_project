CatProxyService v30 — VIP限定・New表示修正版

これまでのマイクラ風クラシックを標準として残しています。
通常版・VIP版に、白とグレーを中心にしたシンプルHTMLを追加しました。
/theme-settings から表示と背景動画を全ページまとめて切り替えられます。
アカウント作成・代行・複製とテーマ設定は、VIP契約中のサイトアカウントで利用してください。
未ログイン・VIP未契約では、トップページからVIP案内へ移動します。
登録・ログイン・VIP購入は引き続き利用できます。

今回の変更
・新規アカウントの作成完了時に、所持キャラを既読にし、図鑑報酬を受取済みにしてNewを解除。
  v27の既読フラグを0へ戻す処理を修正しました。図鑑XPは追加せず、プリセットのXP値を維持します。
・全種別の新規アカウントで、ランク100ごとのランクアップセール案内を非表示に設定。
・作成済みアカウントは、VIPの代行で「所持キャラのNew非表示（図鑑報酬を受取済み）」を選べます。
  ランクアップ案内には「ランクアップポップアップ非表示」を選んでください。
・サービス機能とAPIキー発行をVIP限定にし、APIへ直接アクセスしても未契約なら拒否。
・中級者・上級者は、日本編1〜3章と未来編1〜2章のお宝をすべて「最高」に設定。
・その他のプリセット内容と抽選範囲、個別設定を優先する動作はv26を維持。
・通常版・VIP版のシンプルHTMLを追加。操作と機能はクラシックと共通。
・HTML/表示と背景を全ページ共通で設定。クラシックへいつでも戻せます。
詳細はV28_CHANGES.txtとTHEME_MANAGER.txtを参照してください。
v26の抽選範囲はV26_CHANGES.txtに記載しています。

起動方法
1. ZIPを解凍します。
2. my_project フォルダで、これまでと同じ環境を使用して起動します。
   
cd C:\Users\a\Desktop\my_project
set PYTHONPATH=.
python Paython/main13.py

3. http://127.0.0.1:5001/ を開きます。

既存環境への更新
設定やDBは、元のZIPの構成を維持しています。
運用している環境へ上書きする際は、その環境の設定・DBを残してください。
Paython/main13.py、templates、staticの更新をまとめて反映してください。
main.pyという名前で運用している場合は、Paython/main13.pyの内容をそちらに反映してください。
