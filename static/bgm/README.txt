CPS BGM フォルダ
================
ここに音楽ファイルを入れると、サイトのBGM選択肢に自動で表示されます。

対応する拡張子: .mp3 / .ogg / .wav / .m4a / .aac / .flac
おすすめ: MP3（ブラウザごとに対応コーデックは異なります）
例: static/bgm/01-control-room.mp3
    static/bgm/02-night-terminal.mp3
サブフォルダのファイルは読み込みません。

GitHubへ追加して、Renderをデプロイすると利用できます。
曲はまだ同梱していません。使用できる音楽ファイルを自分で追加してください。
このフォルダの音楽はサイト利用者にも公開されます。

再生方法:
画面右下「表示 / BGM / Language」を開く → 曲を選ぶ →「再生」。
音量・曲・繰り返し・再生位置はブラウザごとに保存されます。
ページ移動後は「再生」を押すと、前回の続きから再生できます。
別のタブへ切り替えると一時停止します。

「端末の音楽ファイルを試す」はそのページだけの試聴です。
選択した端末のファイルはアップロードしません。
ファイルをみんなで使うにはこのフォルダに入れてデプロイしてください。
