テーマ設定: /theme-settings
テーマ設定の利用・背景動画の追加には、VIPのサイトアカウントが必要です。

HTML / 表示
・クラシック: これまでのマイクラ風。標準の表示です。
・シンプル: 白・グレーを中心にした表示。標準背景は無地です。
通常版はindex_simple.html、VIP版はvip_simple.htmlを追加しています。
機能は既存HTMLを継承し、フォームや処理を共通にしています。
ログイン・アカウント管理・VIP購入などのページも同じテーマへ切り替わります。

操作
・表示と背景動画を選び、「全ページに適用」でまとめて保存します。
・「適用してサイトを見る」で保存してトップページへ移動します。
・「テーマを初期状態に戻す」で全ページを標準のクラシックへ戻します。
ページごとの選択・リセットはありません。

背景
動画を選択すると、クラシック・シンプルとも全ページに同じ背景を表示します。
従来のページ別設定は、通常版→VIP版→その他の順で既存の選択を1つ引き継ぎます。
選択した動画が削除されている場合は標準背景で表示します。
動画アップロードは、全利用者が選べる背景候補への追加です。

保存
表示はCookie、背景の選択はlocalStorageへ保存します。
設定はそのブラウザ内の全ページへ適用され、他の利用者の設定は変わりません。
別のブラウザ・端末では、同じテーマを選んでください。
過去のワイド・にゃんこ風のCookieはクラシックとして扱います。

【v30 黒テーマ・英語UI】
テーマ設定に黒と日本語/Englishを追加。各ページ右下にも表示と言語の切替を追加。
設定はCookieでブラウザ内の全ページに共通適用。標準はクラシック・日本語。
言語とテーマは独立して変更できます。黒テーマの標準背景は無地、動画を指定すれば共通背景を適用。
英語UIにはJavaScriptが必要です。フォーム値、コード、ID、チャット本文、ユーザー名は変更しません。
キャラ・ステージの固有名詞は日本版のゲームデータの名称を維持します。
