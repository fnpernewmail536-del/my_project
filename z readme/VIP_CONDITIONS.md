# 現在値を基準にした条件付き指定（2026-10-15）

ローカルチャット版 CatProxyService_LocalChat.zip の版12で追加された条件付き処理を、
既存の公開サイトのVIP選択画面に移植しました。チャットへの文章入力ではなく、
「範囲指定・レア度別レベル・除外（追加）」内の
「現在値で条件分岐・加算・倍率・保持（最新版）」から設定します。

## 使い方

1. 通常の一括チェック・個別キャラ選択・数量範囲を解除します。
2. 「条件付き指定を使用」にチェックし、「指定を追加」を押します。
3. 変更対象・変更方法・値を設定します。固定値も同じ欄に追加できます。
4. 必要なら現在値の条件を追加します。複数条件はすべて満たす場合だけ実行します。
5. 例外は別の指定として追加し、対象名・No.番号を入力します。
6. 内容確認後に、通常の代行／アカウント作成ボタンで実行します。

通常の一括指定との混在は、保持指定を上書きしないよう開始前に拒否します。
アカウント作成では「新規アカウント」を選択してください。
追加設定だけのプリセット登録・復元にも対応します。代行と作成の設定は独立です。

## 対応する変更

- 通貨・チケット：固定値、加算・減算、倍率と切り捨て、範囲抽選、上限、値を減らさない指定。
- 現在値の比較：未満、以下、同値、除外、以上、超過、偶数、奇数。
- キャラ：レア度、コラボ／非コラボ、コラボ名、正式名・形態名・No.番号、
  ちび／大狂乱／特急系、第2・3形態の定義による対象選択。
- 基本Lv・＋値・所持状態による条件分岐。指定しない値を保持。
  レベル・＋値の上限は unitbuy.csv の対象行で照合し、＋非対応は0まで。
- 未所持のみの解放、名前による解放状態保持。解放だけではレベルを変更しません。
  ロックしたままのキャラにレベル・本能を変更しません。
- 実装本能のMAX、移動速度本能保持、名前による本能保持、現在の本能Lvによる条件。
- 種類別アイテム、Sランクだけの本能玉、指定個数以上なら保持。
  装着済み本能玉は対象にしません。
- 章別のお宝・クリア。普通のお宝を保持、クリア済みだけ最高のお宝など。
- レジェンド3系列の冠数、4冠保持、最終ステージの1つ前まで、
  章ごとの現在クリア済みの次の冠まで。
- 定義済みイベント・コラボ・ランキングの間・異次元コロシアム・魔界のクリア。
- ガマトト隊員の不足分をレジェンドで補充、既存レジェンドを残して他隊員だけ変更。
- 既存処理につながる施設・オトート・神社・ガマトトLv.MAX・エラーキャラ削除。

すべて変更前の値で評価します。同じ対象には1回だけ書き込み、名前による個別指定を
全体指定より優先します。同じ詳細度・同じ値への指定では後の指定を採用します。
種類別アイテム・Sランク指定も全種類・全ランク指定より優先します。
値は対象の保存上限までに収めます。「現在値を減らさない」では上限を超える既存値も保持します。
第1〜3形態の解放指定は既存の解放形態を減らさず、使用形態を変えません。

## 保持と検証

編成10枠、使用形態、お気に入り、並び順を保持し、適用後に照合します。
BCSFEの実際のバイト列で保存・再読込し、編集対象・保持対象・保存版数を照合します。
不一致は既存ワーカーの復旧処理へ送られ、最終アップロードを止めます。
定義不足・対象名の曖昧さ・未対応条件は引き継ぎ取得前に停止します。
既存のVIP認証・試用権予約・ジョブ・復旧記録・通知処理を使用します。
ローカルチャットの別サーバーやログイン省略処理は公開しません。

現在開催中のコラボの自動判定、属性・特性条件、第4形態の自動解放、
降臨全体の条件付きクリア、曖昧な数量には対応していません。
プレイ時間や未来編採点など通常の詳細項目との混在も拒否します。
これらは別の実行で既存画面から指定してください。54番の富士山EX接続は変更していません。
