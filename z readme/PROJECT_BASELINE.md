## 15.7.1・自動更新の対応内容と確認範囲

- 通信・新規作成・複製・編集後保存の最低版をJP 15.7.1へ変更。以降は公式日本版ストアの最新公開版数を自動確認。
- 起動時と稼働中1時間ごとに、ゲーム版数・キャラ定義・取得可能なUR報酬定義をバックグラウンドで確認。
- キャラ定義はbattlecatsinfoとBCDataを取得し、番号・レアリティ・形態数を検証して反映。版数とキャラ定義の取得状況を分離。
- 通信失敗時は前回の検証済みデータを保持し、5分後に再試行。更新のために画面表示を待たせない。
- 開始済みジョブの版数は途中で切り替えず、次の処理から新しい公開版を使う。
- 更新キャッシュはBACKUP/game_updates.jsonへ原子的に保存し、再起動時に再利用。
- 取得した対象版より新しいセーブの版数は保持。
- キャラ一覧とUR報酬の前回の修正を維持。
- 旧版の定義で、新版の獲得済み形態や進化権を消さないように修正。
- 4つの作成用テンプレートの保存・再読込、UR報酬の受取済み化／未受取化、追加キャラ・形態の編集を確認。
- BGM、背景、HTML、環境設定、保存済みデータは元のZIPから変更なし。
- 実際の15.7.0アカウントの引き継ぎ・ゲーム起動、新追加の保存フィールドの解釈は未確認。

同梱キャラ定義は**JP 15.7.0**。BCDataのJP 15.6.0を基に、battlecatsinfoの2026年10月6日公開データで追加キャラ・新形態・本能差分を補完。

## 適用方法

既存の環境に適用する場合、`main13.py` をルートの同名ファイルへ上書きし、再起動する。
ブラウザはCtrl＋F5で再読込。Renderでは変更をGitへ反映して再デプロイする。
既存の `.env` とDBは保持する。BGM・背景・HTMLの上書きは不要。
自動更新の仕様・確認方法・対応範囲は、同じフォルダのAUTO_UPDATE.mdを参照。

データ取得元のメタデータ:
https://git.battlecatsmodding.org/fieryhenry/BCData/raw/branch/main/metadata.json
