# 代行チャットの入力画面と読み取り改善

## 使い方

VIP画面の「モード選択」に04「代行チャット」を追加しました。`/chat/` でも開けます。
チャット右上のテーマ選択は白・黒の2種類。ブラウザーに選択を保存し、初期値は白です。

既存アカウントは依頼を入力し、引き継ぎコードと認証番号を専用欄から登録して確認します。
コードは専用欄の登録レスポンス・チャット履歴・Cookieへ表示/保存しません。
入力情報は従来どおりサーバーメモリ内で保持し、20分や再起動で入力し直します。
コードを編集途中の状態では確認ボタンを隠し、登録すると古い確認IDを無効にします。

新規作成は利用モードを変更し、アカウント種別と作成数を「反映」してください。
種別：初期・初心者・中級者・上級者。作成数：1〜5個。
初期アカウントは追加の編集指定なしでも作成できます。希望があれば文章で追加できます。
新規作成に引き継ぎ情報は不要。作成前バックアップは対象外として停止します。
モード変更時は旧依頼と引き継ぎ情報を消去し、別の依頼として確認し直します。
作成後は発行できた全アカウントのコードを表示し、途中失敗時も作成済み分を残します。

## 日本語の読み取り

- 例：猫缶を45000個にしてもらえますか？
- 例：ねこ缶は四万五千個にしてほしいです
- 例：猫缶は45000で、XPはMAXにして、NPは1000で頼む
- 例：猫缶は1000個から2000個の間でランダム
- 例：レアは基本レベル50で、プラスは30にして
- 例：レアの＋値が20未満なら＋値30

表現の整理・読み取り項目数・要確認件数を表示します。曖昧な項目の候補はクリックして訂正できます。
料金文、共有数量、対象の除外、否定、条件の範囲を優先して保持します。
外部の生成AI/APIは追加していません。既存の解析処理に、対応文型・語尾・数値の整理と
候補提示を追加したものです。完全な日本語理解、未知の依頼の解釈、推測の正しさを保証しません。
根拠のない理解率・確信度のパーセントは表示しません。未対応操作を別操作に置き換えません。
