# 通常CPS：レジェンド全ステージの星・未クリア指定（第15版・2026-10-25）

第15版では「指定した星に揃える」へ切り替えると、星と適用方法の選択欄まで無効になる不具合を修正しました。切替後も★0〜4を選択でき、「追加」へ戻すこともできます。

## 使い方

1. 「代行」または「新規作成」で、旧・真・零レジェンドの「星・未クリア指定」を選びます。
2. 「レジェンド全ステージの進行状況」で、適用方法を選びます。
3. クリアを追加するだけなら「クリア済みを残して追加」、★4クリア済みから戻す場合は「指定した星に揃える」を選びます。
4. 星を選びます。「指定した星に揃える」では「全て未クリア（★0）」も選べます。

| 適用方法・星 | ★4クリア済みから実行した結果 |
| --- | --- |
| 追加・★1まで | ★4クリア済みを保持 |
| 揃える・★1まで | 全マップの★1をクリア、★2〜4を未クリアに戻す |
| 揃える・★2まで | 全マップの★1・2をクリア、★3・4を未クリアに戻す |
| 揃える・全て未クリア | 全マップ・全冠のクリア回数と進行を0に戻す |

「全ステージ全クリア」を選んだ場合も、旧・真・零ごとに別の適用方法・星を指定できます。揃える指定を最後に適用するため、他の一括クリアで上位の星が再クリアされません。未選択のシリーズ、未実装の星、定義がない新しいマップをこの指定で変更することはありません。

未クリアに戻す冠は、クリア回数・進行・選択位置をリセットします。次に遊べる冠は解放状態とし、全て未クリアでは最初のマップの★1から始められる状態にします。クリアを残す冠の既存クリア回数、取得済みキャラ・メダル・報酬の取得履歴は保持します。報酬の再取得用リセットではありません。

星と適用方法は既存のプリセットへ保存・復元します。旧プリセットや未指定時の既定値は「追加・★4まで」です。代行と新規作成は別々の設定を保持し、リセットで既定値へ戻します。

詳細選択画面にも同じ適用方法・星指定があります。「追加」では従来の章・ステージ・星ごとの選択を使えます。「個別指定」と表示される場合は、その個別選択を維持します。「揃える」では全ステージへの指定を使うため、個別指定欄を無効にします。追加へ戻すと、それまでの個別選択を復元します。

## 適用

起動中のCPSを終了し、CPS_Legend_Crowns_Update.zip内のmy_projectフォルダーの中身を、既存のmy_projectフォルダーへ上書きします。起動CMDで再起動し、ブラウザーでCtrl＋F5を押して再読み込みしてください。Renderには更新後のソースを再デプロイしてください。この作業では公開サイトのデプロイを行っていません。

累積差分には、これまでの代行チャットやキャラ育成の修正も含みます。.env・DB・BACKUP・利用者の保存データは含めません。

## 検証

保存処理は第14版のPython411件（失敗0件、スキップ8件）から変更していません。第15版では、通常/詳細画面・代行/新規作成・旧/真/零の選択欄が実際に有効な状態で操作できることをDOM操作で確認しました。既存の確認UI7フロー・代行チャットの画面操作も成功しています。ブラウザーの実レイアウト・実機動作は未検証です。

- 星の型・範囲・対象シリーズを、APIキー使用・受付・引き継ぎ取得より前に検証します。無効な指定や定義不足を「全冠」に置き換えません。
- 定義を受付時に固定し、適用直前に比較します。対象が変わった場合は編集を停止します。
- 追加では、個別選択で解除したステージを再選択しません。揃える指定と同じシリーズの個別指定が混在するAPI入力は拒否します。
- 通常・詳細画面の代行/新規作成、追加と0〜4冠への進行指定、シリーズ別指定、プリセット互換性、リセットをDOM操作で検証します。
- 旧・真・零の実際の保存形式で、★4→★1→全未クリア→★2→★4を保存・再読込して確認します。処理時にも保存・再読込し、指定の進行を保存できなければコード発行を停止します。
- 追加時の既存上位冠、残す冠の回数、未選択シリーズ、未定義マップ・冠・保存配列の余白、キャラ・編成・取得履歴の保持も確認します。
- 実アカウントの引き継ぎ・ゲームサーバーへの送信は行っていません。
