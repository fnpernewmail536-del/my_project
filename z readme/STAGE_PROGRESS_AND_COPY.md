# ステージ進行の調整・引継ぎコードのまとめてコピー（第16版・2026-10-25）

## ステージ進行を戻す・揃える

通常CPSと詳細画面の代行・新規作成に「ステージ進行を揃える」を追加しました。従来の一括クリアを選択しなくても、この欄の指定だけで実行できます。

1. 選択項目の先頭にある「ステージ進行を揃える」を開きます。
2. 系統と、対象の章・マップを選びます。「この系統の全章・全マップ」も選べます。
3. 「全クリア」「全て未クリア」「指定ステージまでクリア」を選びます。途中までの場合は数を入力します。
4. 複数の星がある場合は「全ての星」または「★1まで」などを選びます。指定より上位の星は未クリアになります。
5. 「この進行指定を追加」を押し、下の一覧を確認します。同じ章・マップ・星への再指定は、最後の指定に置き換わります。
6. 他の項目と合わせて、代行または新規作成を実行します。

例：日本編を1章クリア・2〜3章未クリアにする場合は、日本編の全章を「全て未クリア」で追加してから、日本編1章だけを「全クリア」で追加します。宇宙編3章を途中までに戻す場合は、宇宙編3章を選んで「指定ステージまでクリア」と数を追加します。

追加した一覧の対象だけを揃えます。別途、一括クリアや詳細指定を選択した場合は、それらの後にこの一覧を適用します。つまり一括クリアと同時に指定しても、戻した進行が再クリアされることを防ぎます。

対象のステージ数より大きい数を、複数マップへ一括指定する場合は、そのマップの実装数までをクリアします。一覧には各マップへ実際に適用する数を表示します。100件を超える一覧には、全件表示ボタンがあります。

## 対応範囲

- 日本編・未来編・宇宙編：それぞれ全3章。章ごとの途中まで・未クリア化。
- ゾンビ襲来：本編各章のクリア状態。
- 魔界編・富士山EX：定義を取得できたステージの進行。
- イベント・コラボ・ランキングの間・にゃんこ塔／異界にゃんこ塔・ネコビタンステージ・レジェンドクエスト・強襲・発掘地図・コラボ強襲・超獣討伐・地底迷宮・異次元コロシアム・にゃんこ道検定。
- 旧・真・零レジェンドは従来の「指定した星に揃える」欄を使います。

配布定義を取得できた章・マップ・星だけを対象にします。定義がない対象を推測で別の保存先へ置き換えません。受付時に対象を固定し、適用時に定義が変わっていたら停止します。

進行を戻す部分のクリア回数は0にします。クリアを残す部分の既存回数、お宝・採点スコア・取得済みキャラ・メダル・報酬履歴は保持します。この欄は進行だけを変更するもので、報酬の再取得・キャラの新規取得用の操作ではありません。地底迷宮では現在階・最高到達階・表示階と、定義のある階のクリアIDを揃え、封印キャラ・編成は保持します。

指定は代行・新規作成で独立し、プリセットにも保存・復元します。「進行指定を全解除」またはモードのリセットで解除できます。旧プリセットには進行指定を追加しません。

## 引継ぎコードを2行まとめてコピー

通常画面・詳細画面の結果、複数アカウントの作成・複製、復旧用コード、使用履歴に「まとめてコピー」を追加しました。代行チャットの結果にも追加しています。

1つのアカウントの引継ぎコードと認証番号を、ラベル付きの2行でコピーします。複数アカウントはそれぞれの組を個別にコピーできます。認証番号の先頭の0も保持します。ブラウザーがコピーを許可しない場合は2行を選択して、手動でコピーできる状態にします。コピーするだけで外部へ送信しません。
