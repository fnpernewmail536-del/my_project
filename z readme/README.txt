キャラ一覧・ユーザーランク報酬 修正版（2026-10-10）

適用方法
1. 起動中のサイトを停止します。
2. 現在の main13.py を別の場所へコピーしてバックアップします。
3. このZIP内の main13.py を、既存の my_project フォルダ直下の同名ファイルに上書きします。
   Paython フォルダ内ではなく、HTML・static・ACCOUNT と同じ階層です。
4. サイトを起動し直し、ブラウザで Ctrl + F5 を押します。
   Renderの場合は変更した main13.py をGitへ反映し、再デプロイしてください。

.env、データベース、BGM、背景、HTML、その他のファイルは上書き不要です。

修正内容
・JP 15.6.0のキャラ名、レアリティ、形態数、本能、ガチャ系列を同梱。
  追加キャラ872～875、キャットマンダディの第4形態、鉄籠のペガサの第3形態に対応。
  未実装の仮名称キャラ876は選択対象にしません。
・取得データが古い／通信に失敗した場合でも、キャラ一覧が旧同梱版に戻らないように修正。
・データ取得時のBCSFEの対話入力待ちを防止。
・キャラ解放・レベル変更が終わった後のユーザーランクで報酬を受取済みに変更。
  未到達の報酬は未受取。未受取化も対応。
・JP 15.6.0のユーザーランク報酬定義346件を同梱し、通信失敗時にも適用。
・新しいセーブの版数を15.5.1へ下げないように修正。

確認済み
・キャラ名API、通信失敗時の一覧、新キャラ解放、追加形態変更。
・キャラ解放／レベル変更とUR報酬受取済み化を同時選択した場合。
・受取済み化／未受取化後のセーブ書き出しと再読込。
・4種類の新規作成用テンプレートのセーブ書き出しと再読込。
・既存BGM、背景、HTML、保存データは変更なし。
実際のアカウントの引き継ぎ・ゲーム起動はこの環境では確認していません。
