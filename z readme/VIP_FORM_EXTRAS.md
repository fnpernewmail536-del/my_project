# 選択画面の追加詳細設定

VIPページの「代行」「アカウント作成」で、選択画面の下部にある
「範囲指定・レア度別レベル・除外（追加）」を開いて使用します。
ローカル注文Botの追加機能を、既存の選択画面へ組み込んだものです。

## 数量の範囲指定

- 変更する数量にチェックを入れ、最小値と最大値を入力します。
- 最小＝最大は固定値です。チェックしていない範囲入力は使用しません。
- 猫缶・XP・NP・チケット等は1項目ごと、配列アイテムと本能玉は種類ごとに独立抽選します。
- 既存の種類別選択がある場合は、その選択範囲だけに適用します。親項目を選択して詳細を全解除した場合は、その空の選択を保持します。
- 既存の種類別選択がない場合は、取得済みの全種類へ適用します。範囲指定だけを追加しても、その数量を変更できます。
- 本能玉は「Sランクのみ」を選べます。他のランクの所持数を保持します。
- 独立抽選なので、別の種類やキャラが同じ値になる場合もあります。

範囲入力はローカル版の上限に合わせています。猫缶58,999、XP99,999,999、NP9,999、
プラチナ・レジェンドチケット各99、マタタビ・獣石・本能玉各998、その他の対象各999。
従来の固定値・個別数量入力の上限は変更していません。

## レア度別レベル・コラボ例外

- レア度ごとに「変更しない」「基本Lvと＋値」「基本Lvだけ」「＋値だけ」「コラボだけ＋値」を選べます。
- 基本Lvは1〜60、＋値は0〜90。キャラごとに範囲内で抽選します。
- 指定しない基本Lv・＋値は、既存の一括レベル変更前の値を保持します。
- コラボの＋値を別指定できます。コラボガチャに含まれる通常ガチャのキャラを、コラボ例外へ巻き込みません。
- コラボ所属定義が不十分な場合は、推測で適用せず、処理開始前にエラーを返します。
- 「基本キャラの設定を全レア度に適用」で6系列をまとめて設定できます。
- 「＋値に対応するキャラのみ」を選ぶと、取得したunitbuy.csvの対応定義を検証します。非対応の＋値は0になります。新しいキャラ等の対応定義を取得できない場合は開始しません。
- 解放・形態は既存の項目で別に指定します。追加レベル指定だけでは解放しません。

例：レアを「＋値だけ」、＋値20〜55、コラボの＋値10〜15に設定すると、
基本Lvを保持し、通常レアとコラボレアにそれぞれの＋範囲を使います。

## キャラ除外・内容確認・プリセット

- 名前検索からキャラを選択するか、No.番号をカンマ区切りで入力します。
- 除外キャラは基本Lv・＋値を保持します。既存の一括レベル変更や指定キャラのレベル変更よりも除外を優先します。
- 除外するのはレベルだけです。別に選択した解放・形態・本能などの操作は適用できます。
- 未知のNo.番号、不正な範囲、未取得の対象定義は処理開始前に拒否します。
- 「追加設定の内容を確認」で内容を表示します。追加設定を使う場合は、実行時にも確認ダイアログを表示します。
- 追加設定は既存のプリセット保存・復元に含めます。追加設定のない古いプリセットは、追加設定なしとして読み込みます。
- 代行とアカウント作成の入力は独立しています。

## 適用

main13.py、HTML/vip.html、static/js/vip-app.js、static/js/vip-form-extras.jsを
同じ位置へ反映し、再起動／Render再デプロイ後にCtrl＋F5で再読み込みします。
既存の.env、DB、保存データは保持します。追加の実行用パッケージはありません。
以前指定された「マイクラ風＋草原」の初期設定も含みます。

## 検証範囲

BCSFEの合成JP 15.5.1セーブで、基本Lv・＋値・除外・コラボ例外・種類別数量・
本能玉Sのみの変更を実行し、保存・再読込で状態と元の保存版数を確認しました。
既存の全Lv.Max＋と併用しても保持対象が残ることを確認しています。
両APIのVIP確認、試用権予約、実行接続、不正入力・定義取得失敗時の開始前停止を確認しています。
実際のVIPテンプレートとJavaScriptをDOM上で実行し、両フォーム、除外キャラ検索、
送信内容、プリセット保存・復元、確認取消時の非実行を検証しています。
実アカウントの引き継ぎ・ゲーム起動と、本番Renderのデプロイは未確認です。

確認用コマンド：

```sh
python -m unittest discover -s tests -v
node --check static/js/vip-app.js
node --check static/js/vip-form-extras.js
```

DOMテストは開発環境だけでjsdomを使用します。Flask実行環境への追加は不要です。

```sh
node tests/test_vip_form_extras.js
```
